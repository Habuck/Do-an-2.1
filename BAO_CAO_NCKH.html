2. Kiến thức nền tảng — Tín hiệu âm thanh, ML, DL

2.1. Sóng âm thanh và tín hiệu số

2.1.1. Sóng âm thanh (Sound Wave)

Âm thanh là sóng cơ học lan truyền qua môi trường (không khí, nước, rắn) dưới dạng dao động áp suất. Sóng âm được đặc trưng bởi:

  • Biên độ (Amplitude) — cường độ âm thanh (loudness), đơn vị Pascal (Pa) hoặc dB
  • Tần số (Frequency) — số dao động/giây, đơn vị Hertz (Hz). Tai người nghe 20Hz–20kHz
  • Pha (Phase) — vị trí trong chu kỳ dao động

Một sóng âm đơn giản (pure tone) biểu diễn dạng hàm sin:

y(t) = A · sin(2πft + φ)   với A = biên độ, f = tần số (Hz), φ = pha

Hình 3. Biểu diễn sóng âm trong miền thời gian — biên độ A và chu kỳ T.

2.1.2. Số hóa âm thanh (Digital Audio)

Để máy tính xử lý, sóng analog phải được số hóa qua 2 bước:

  • Lấy mẫu (Sampling): Đo biên độ tại các thời điểm đều đặn. Tần số lấy mẫu (Sample Rate, SR) = số mẫu/giây. Theo định lý Nyquist, SR phải ≥ 2× tần số cao nhất cần ghi. Dự án dùng SR = 16,000 Hz (đủ cho giọng nói, vì tiếng nói chủ yếu nằm dưới 8kHz).
  • Lượng tử hóa (Quantization): Mỗi mẫu được biểu diễn bằng số bit nhất định. CD dùng 16-bit (65,536 mức). Dự án dùng float32 (giá trị liên tục trong [-1, 1]).

SR = 16,000 Hz → 1 giây = 16,000 samples → 8 giây = 128,000 samples

Hình 4. Quá trình số hóa: Sóng analog → Lấy mẫu (16kHz) → Mảng numpy float32.

Trong dự án: librosa.load(path, sr=16000, mono=True) đọc file audio bất kỳ, resample về 16kHz, chuyển stereo→mono, trả về numpy.ndarray float32.

2.2. Biến đổi Fourier và STFT

2.2.1. Biến đổi Fourier (Fourier Transform)

Mọi tín hiệu phức tạp đều có thể phân tách thành tổng các sóng sin đơn giản ở các tần số khác nhau — đây là nguyên lý của Biến đổi Fourier (Joseph Fourier, 1822). Chuyển tín hiệu từ miền thời gian sang miền tần số:

X(f) = ∫ x(t) · e-j2πft dt   (Fourier Transform liên tục)

Dạng rời rạc cho tín hiệu số (DFT — Discrete Fourier Transform):

X[k] = Σn=0..N-1 x[n] · e-j2πkn/N   với k = 0,1,...,N-1

FFT (Fast Fourier Transform) là thuật toán tính DFT nhanh với O(N log N) thay vì O(N²). Thư viện librosa dùng FFT qua numpy.

2.2.2. STFT — Short-Time Fourier Transform

FFT cho biết tần số tổng thể nhưng không cho biết tần số thay đổi theo thời gian. STFT giải quyết bằng cách chia tín hiệu thành các frame ngắn (window), áp dụng FFT trên từng frame:

STFT(t,f) = Σn x[n] · w[n-t] · e-j2πfn

Tham số quan trọng:

  • n_fft = 2048: Kích thước FFT (2048 samples ≈ 128ms ở 16kHz) — độ phân giải tần số
  • hop_length = 512: Bước nhảy giữa các frame (512 samples ≈ 32ms) — độ phân giải thời gian
  • Window function: Hann window — giảm spectral leakage

Hình 5. STFT chuyển waveform sang spectrogram — trục X: thời gian, trục Y: tần số, màu: năng lượng.

2.3. Thang Mel và MFCC

2.3.1. Thang Mel (Mel Scale)

Tai người không nghe tần số tuyến tính — sự khác biệt giữa 100Hz và 200Hz (nghe rõ) lớn hơn giữa 8000Hz và 8100Hz (gần như giống nhau). Thang Mel (Stevens, 1937) mô hình hóa cảm nhận tần số của tai người:

m = 2595 · log10(1 + f/700)   (Hz → Mel)

f = 700 · (10m/2595 - 1)   (Mel → Hz)

Ví dụ: 1000 Hz ≈ 1000 Mel, nhưng 8000 Hz ≈ 2840 Mel (không gấp 8 lần).

2.3.2. Mel-spectrogram

Áp dụng Mel filterbank (n_mels bộ lọc tam giác trên thang Mel) lên spectrogram, rồi chuyển sang thang dB:

Mel-spec = 10 · log10(Wmel · |STFT(y)|²)   với Wmel ∈ ℝ128×1025

2.3.3. MFCC — Mel-Frequency Cepstral Coefficients

MFCC là đặc trưng âm thanh phổ biến nhất trong speech processing. Bước tính:

  1. Tính Mel-spectrogram (log power spectrum trên thang Mel)
  2. Áp dụng DCT (Discrete Cosine Transform) để decorrelate → giữ lại n_mfcc hệ số đầu tiên

MFCC = DCT(log(Wmel · |STFT(y)|²))   giữ 40 hệ số đầu (n_mfcc=40)

MFCC hệ số thấp (0-12) mô tả hình dạng tổng thể của phổ (formants — cộng hưởng thanh quản). Hệ số cao mô tả chi tiết fine-grained. Thường chỉ cần 13-40 hệ số đầu.

Hình 6. Pipeline tính MFCC: Waveform → STFT → Mel filterbank → Log → DCT → 40 coefficients.

2.5. Machine Learning — RandomForest và KNN

2.5.1. Random Forest (Breiman, 2001)

Random Forest [8] là phương pháp ensemble learning, kết hợp nhiều cây quyết định (decision trees) huấn luyện trên các tập con ngẫu nhiên (bagging):

  1. Từ dataset N mẫu, tạo B bootstrap samples (lấy mẫu có hoàn lại)
  2. Với mỗi sample, train 1 decision tree, tại mỗi node chọn ngẫu nhiên √p features
  3. Kết quả cuối = majority voting (classification) hoặc average (regression)

ŷ = mode(h1(x), h2(x), ..., hB(x))   với B = 200 trees trong dự án

Ưu điểm: Ít overfitting nhờ ensemble, không cần normalize features, train nhanh, interpretable.

2.5.2. K-Nearest Neighbors (KNN)

KNN phân loại mẫu mới dựa trên K mẫu gần nhất trong không gian đặc trưng. Không có giai đoạn "training" thực sự — chỉ lưu toàn bộ dữ liệu.

ŷ = mode(yi : xi ∈ K-nearest(x))   với distance = √(Σ(xj-xij)²)

Dự án dùng K=5, Euclidean distance, 6 features. Đơn giản nhưng hiệu quả khi feature space có phân tách rõ ràng (male vs. female).

2.6. Deep Learning — Neural Networks

2.6.1. Perceptron và MLP

Một neuron nhân tạo nhận đầu vào x, nhân với trọng số w, cộng bias b, qua hàm kích hoạt:

y = σ(wTx + b)   với σ = ReLU, Sigmoid, Tanh, ...

Multi-Layer Perceptron (MLP) xếp chồng nhiều lớp neuron. Classifier head trong dự án là MLP 2 lớp:

classifier = nn.Sequential(
    nn.Linear(1024, 1024),    # Lớp ẩn: 1024 → 1024 (1,049,600 params)
    nn.ReLU(),                 # Hàm kích hoạt: max(0, x)
    nn.Dropout(0.1),           # Regularization: tắt 10% neuron ngẫu nhiên
    nn.Linear(1024, 7),        # Lớp output: 1024 → 7 classes
)   # Tổng: ~1M trainable parameters

2.6.2. CNN — Convolutional Neural Network

CNN sử dụng convolution filters trượt qua dữ liệu, phát hiện pattern cục bộ. Trong wav2vec2, CNN 1D trượt qua raw waveform để trích xuất local features:

(Conv1D * y)[t] = Σk w[k] · y[t+k]   (tích chập 1 chiều)

wav2vec2 dùng 7 lớp Conv1D với stride giảm dần (5,2,2,2,2,2,2), tổng downsample 320×. Nghĩa là cứ 320 samples (20ms ở 16kHz) tạo ra 1 frame representation.

2.6.3. Backpropagation và Gradient Descent

Training neural network = tìm weights w sao cho loss function nhỏ nhất. Backpropagation tính gradient ∂L/∂w bằng chain rule, rồi cập nhật:

wt+1 = wt - η · ∂L/∂wt   (Gradient Descent, η = learning rate)

Adam optimizer (dự án dùng) cải tiến SGD bằng adaptive learning rate cho từng parameter, dùng momentum bậc 1 (β₁=0.9) và bậc 2 (β₂=0.999).

2.7. Transformer và Self-Attention

2.7.1. Self-Attention Mechanism

Transformer (Vaswani et al., 2017) đã cách mạng hóa NLP và speech. Cơ chế cốt lõi là Self-Attention: mỗi vị trí trong chuỗi "nhìn" tất cả các vị trí khác để tính representation:

Attention(Q,K,V) = softmax(QKT/√dk) · V

Với Q (Query), K (Key), V (Value) là các phép chiếu tuyến tính từ input. √dk là scaling factor. Multi-Head Attention chạy song song H heads rồi concatenate:

MultiHead(Q,K,V) = Concat(head1,...,headH) · WO

2.7.2. Transformer Encoder Block

Mỗi block gồm: Multi-Head Self-Attention → Add & Norm → Feed-Forward Network → Add & Norm. wav2vec2 dùng 12 blocks, mỗi block có 16 attention heads, hidden size 1024.

Hình 7. Transformer Encoder Block — Multi-Head Self-Attention + FFN + Residual connections.

2.8. Self-Supervised Learning và wav2vec 2.0

2.8.1. Self-Supervised Learning (SSL)

SSL là paradigm training mới: model học từ dữ liệu không nhãn bằng cách tự tạo "nhãn" từ dữ liệu. Ví dụ: BERT mask một số từ, dự đoán lại. wav2vec2 mask một số frames, dự đoán lại từ context. SSL rất hiệu quả vì dữ liệu không nhãn gần như vô hạn.

2.8.2. wav2vec 2.0 (Baevski et al., 2020)

Pretrained trên 960 giờ audio LibriSpeech (tiếng Anh, không nhãn). 3 thành phần:

  1. Feature Encoder (CNN): Raw waveform → latent representations zt
  2. Quantization: zt → discrete tokens qt qua Gumbel-Softmax (codebook learning)
  3. Context Network (Transformer): Mask một số zt, dùng context dự đoán qt tương ứng

Loss function = Contrastive loss: phân biệt qt đúng với K distractors + diversity loss.

L = -log(exp(sim(ct,qt)) / Σq̃ exp(sim(ct,q̃)))   (InfoNCE loss)

Sau pretrain, wav2vec2 học được contextualized speech representations chất lượng cao — mỗi frame 20ms được biểu diễn bằng vector 1024 chiều chứa thông tin ngữ nghĩa phong phú.

Transfer Learning: Dự án dùng pretrained wav2vec2 làm frozen feature extractor (không train lại) → chỉ train classifier head nhẹ (~1M params) trên dữ liệu cảm xúc. Giống cách dùng ResNet pretrained cho image classification.

2.9. Dynamic Time Warping (DTW)

DTW (Sakoe & Chiba, 1978) [5] so sánh hai chuỗi thời gian có tốc độ khác nhau. Ví dụ: 2 người nói cùng 1 câu nhưng nhanh/chậm khác nhau. DTW tìm alignment tối ưu bằng quy hoạch động:

D[i,j] = cost(s₁[i], s₂[j]) + min(D[i-1,j], D[i,j-1], D[i-1,j-1])

Độ phức tạp O(n·m). Dự án dùng Fast DTW với Sakoe-Chiba band (radius=10-20) giảm xuống O(n·radius).

Hình 8. DTW warping path — alignment tối ưu giữa 2 chuỗi có tốc độ khác nhau.

2.10. FP16, GPU và DirectML

2.10.1. Float16 (FP16) — Half Precision

Số thực trong máy tính lưu theo chuẩn IEEE 754. FP32 (float32) dùng 32 bit (1 sign + 8 exponent + 23 mantissa). FP16 (float16) dùng 16 bit (1+5+10) — tiết kiệm 50% bộ nhớ và tăng tốc tính toán:

PrecisionBitsRangeVRAM cho wav2vec2Throughput
FP3232±3.4×10³⁸~720 MBBaseline
FP1616±65,504~360 MB~2× faster

2.10.2. GPU — Graphics Processing Unit

GPU có hàng nghìn cores nhỏ, xử lý song song hàng triệu phép tính cùng lúc. Deep Learning tận dụng GPU vì matrix multiplication (phép toán cốt lõi) rất song song. VRAM (Video RAM) chứa model weights + input data + activations.

2.10.3. DirectML — AMD GPU backend

CUDA (NVIDIA) là backend GPU phổ biến nhất nhưng chỉ chạy trên NVIDIA. DirectML [7] (Microsoft) là API hardware-accelerated ML chạy trên mọi GPU Windows (AMD, Intel, NVIDIA). Tích hợp qua torch-directml [10].

Khác biệt quan trọng với CUDA:

  • Không hỗ trợ torch.cuda.amp.autocast → phải cast FP16 thủ công bằng .half()
  • Không có cuda.empty_cache() → dùng gc.collect() + del tensor
  • Khi hết VRAM: CUDA raise OutOfMemoryError, DirectML hang (treo) → phải dùng batch size cố định

Hình 9. Phân bổ VRAM 16GB: model 0.36GB + batch 5GB + activations 6GB + features + headroom.

Tổng kết: Chương này cung cấp nền tảng lý thuyết cho toàn bộ dự án — từ cách âm thanh được số hóa, qua các phương pháp trích xuất đặc trưng (STFT, Mel, MFCC), đến các thuật toán ML/DL (RandomForest, KNN, CNN, Transformer, SSL) và kỹ thuật tối ưu phần cứng (FP16, DirectML).

# core.py:57-69 — Trích 6 đặc trưng trung bình từ 1 audio
def extract_features(y, c=Cfg()):
    mfcc   = librosa.feature.mfcc(y=y, sr=c.sr, n_mfcc=c.n_mfcc)   # (40, T)
    mel    = librosa.power_to_db(librosa.feature.melspectrogram(
                 y=y, sr=c.sr, n_mels=c.n_mels), ref=np.max)        # (128, T)
    chroma = librosa.feature.chroma_stft(y=y, sr=c.sr)              # (12, T)
    zcr    = librosa.feature.zero_crossing_rate(y)                   # (1, T)
    rms    = librosa.feature.rms(y=y)                                # (1, T)
    f0,_,_ = librosa.pyin(y, fmin=C2, fmax=C7, sr=c.sr)            # (T,)
    return {"mfcc_mean": mfcc.mean(), "mel_mean": mel.mean(),
            "chroma_mean": chroma.mean(), "zcr_mean": zcr.mean(),
            "rms_mean": rms.mean(), "f0_mean": np.nanmean(f0)}

5extract_features_gpu() — Trích features (dòng 175-240)

def extract_features_gpu(w2v, extractor, audio_list, device, backend,
                         batch_size=32, quiet=False):
    for batch_audio in chunks(audio_list, batch_size):
        inputs = extractor(batch_audio, sampling_rate=SR, return_tensors="pt",
                          padding=True, max_length=MAX_LEN, truncation=True)
        input_vals = inputs.input_values.to(device)
        if USE_FP16: input_vals = input_vals.half()  # Manual FP16 (DirectML)
        with torch.no_grad():
            out = w2v(input_vals).last_hidden_state   # (B, T, 1024)
            # Attention-mask pooling: chỉ average trên frames thực, bỏ padding
            if inputs.attention_mask is not None:
                mask = inputs.attention_mask.to(device).unsqueeze(-1)
                if mask.size(1) != out.size(1):  # Align: wav2vec2 downsample T
                    mask = F.interpolate(mask.T(1,2), out.size(1), "nearest").T(1,2)
                pooled = (out*mask).sum(1) / mask.sum(1).clamp(min=1e-6)
            else: pooled = out.mean(dim=1)
            features.append(pooled.float().cpu())     # FP16→FP32, → CPU RAM
        del input_vals, out; gc.collect()              # Free VRAM ngay
    return torch.cat(features, dim=0)                  # (N, 1024)

7.1. _fast_dtw() — Dynamic Time Warping

# pronunciation.py — Fast DTW với Sakoe-Chiba band
def _fast_dtw(seq1, seq2, radius=10):
    n, m = len(seq1), len(seq2)
    D = np.full((n+1,m+1), np.inf); D[0,0] = 0.0
    scale = m / n
    for i in range(1, n+1):
        jc = int(round(i * scale))              # Projected center
        for j in range(max(1,jc-radius), min(m,jc+radius)+1):
            cost = np.linalg.norm(seq1[i-1] - seq2[j-1])
            D[i,j] = cost + min(D[i-1,j], D[i,j-1], D[i-1,j-1])
    return D[n,m] / (n+m)    # Normalized distance

D[i,j] = cost(s₁[i],s₂[j]) + min(D[i-1,j], D[i,j-1], D[i-1,j-1])

def _extract_cough_features(y, sr=16000):
    yt, _ = librosa.effects.trim(y, top_db=20)
    # 13 MFCC (mean+std), Spectral (centroid, bandwidth, rolloff, flatness)
    rms = librosa.feature.rms(y=yt)[0]
    q = len(rms) // 4
    feats["energy_attack"]  = mean(rms[:q])       # 1/4 đầu: burst mạnh
    feats["energy_sustain"] = mean(rms[q:])        # 3/4 sau: decay
    feats["attack_ratio"]   = attack / sustain     # Ho: cao, Nói: thấp
    feats["duration"]       = len(yt) / sr         # Ho ngắn, nói dài
    return feats  # ~35 features → RandomForest(150), 3 classes
